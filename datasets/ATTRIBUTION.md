# Public dataset attribution

Downloaded on 27 October 2026 for local research-model training. Each source is
licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
Raw and processed records are not application validation evidence.

- Mishra, Sandhya; Soni, Devpriya (2022), “SMS PHISHING DATASET FOR MACHINE LEARNING AND PATTERN RECOGNITION,” Mendeley Data, V1. https://doi.org/10.17632/f45bkkt8pr.1
- Munoz, Miriam; Islam, Muhammad (2025), “A Balanced Dataset for Spam and Smishing Detection using Large Language Models (LLMs),” Mendeley Data, V1. https://doi.org/10.17632/vmg875v4xs.1
- Almeida, Tiago; Hidalgo, José María (2011), “SMS Spam Collection,” UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84
- Potpelwar, Rachana; Kulkarni, Uday; Waghmare, Jaishri (2025), “LegitPhish Dataset,” Mendeley Data, V2. https://doi.org/10.17632/hx4m73v2sf.2
- Ahmed, Al Rafi; Islam, Gazi Faizul (2025), “Financial scams detection dataset,” Mendeley Data, V2. https://doi.org/10.17632/znsk27yk3h.2

Processing changes are documented in `processed/manifest.json`: normalization,
exact deduplication, exclusion of conflicting/unlabeled/malformed records, and
LegitPhish label inversion to the application convention (0 legitimate, 1 phishing).
