# EIS’26 demonstration walkthrough

Suggested duration: 5–7 minutes. Use only fictional content from datasets/samples.json. Do not show real bank credentials or actual private messages.

1. **Problem and purpose (40 seconds):** open overview. Explain the Malaysian community audience and tagline. State that the platform supports preventive decisions and independent verification; national scam reduction is not measured.
2. **Message scan (60 seconds):** use the fictional part-time-job sample. Show dynamically computed HIGH result, indicator score labeled heuristic, upfront payment, urgency and earnings warnings. Expand explanations and show next steps. Compare benign meeting text and emphasize that LOW is not a safety guarantee.
3. **Bilingual accessibility (30 seconds):** switch to BM and analyze the fictional prize sample. Show Malay explanations, mobile menu and dark mode.
4. **URL check (40 seconds):** enter https://maybank.verify.example.com/login. Explain recognized brand outside its reference official domain. No DNS/HTTP request or redirect is performed. Do not visit suspicious links. Mention that legitimate domains can still host malicious content.
5. **Telegram (60 seconds):** with your configured bot in a private conversation, forward the same fictional message. Compare risk/score/indicator list with the web result. They use the same analyzer; IDs/timestamps differ. If credentials are unavailable, demonstrate the implemented handler tests and clearly state live delivery is unverified.
6. **Screenshot (40 seconds):** upload a self-created screenshot of fictional content, review/redact OCR text and analyze it. If Tesseract is unavailable, show the explicit fallback and paste text; do not pretend OCR ran.
7. **Learning and impact (60 seconds):** complete a pre-check, read the lesson, and answer the post-check. Open dashboard. Describe coarse installation counts, repeated attempts and development activity. These are neither unique people nor national cybercrime statistics. A repeated short quiz is practice, not causal evidence of literacy improvement.
8. **Trust/business (40 seconds):** open official resources and About. Explain independent status, SDGs 9/16 with 4/10 support, free community tier and proposed institutional awareness/training tier. No billing in MVP.

Optional technical questions: show API docs, Alembic schema, test results and shared service import in both web routes/bot. Explain model preparation without claiming a trained model. Discuss authorized dataset collection, false positives, calibration, independent pilot design, retention and secure deployment as next validation work.

Rehearsal checklist: start backend/frontend; verify health; configure/test token; verify Tesseract languages; prepare fictional screenshot; ensure no token is visible; confirm official links; run tests; avoid production/private data. Do not delete real records to reset charts—use a separate demonstration database.
